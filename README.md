### 👋 About Me

I'm an ML systems engineer passionate about **large language model infrastructure** — from high-throughput inference serving to RL post-training. I work across the full stack: CUDA kernels, distributed training, and serving frameworks.

- 🔭 Currently exploring **efficient attention** (linear/flash) and **RL post-training kernels**
- 🌱 Forking & hacking on: `vllm`, `sglang`, `flash-linear-attention`, `RL-Kernel`, `GEAK`
- 💬 Ask me about LLM serving, Triton kernels, and FSDP/training infra
- ⚡ Fun fact: I measure success in tokens-per-second
